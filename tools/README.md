# tools/

A directory of pure development, build-prep, data-package publishing, engine reverse-engineering, and packet-capture debugging tools (all automated checks and test suites live in `tests/`).

## Directory Structure

### `tools/engine/` — GTA:SA v2.10 engine extraction & offline reverse engineering
| Script | Purpose |
|---|---|
| `prepare_gtasa.py` | Before building, extracts `libGTASA.so`, `libImmEmulatorJ.so`, and lightweight APK assets to local storage (already `.gitignore`d) from an ADB device with GTA:SA v2.10 installed (`--from-adb`) or a local APK/Split-APK (`--apk` / scans `dist/gtasa*.apk` by default). Automatically skips large OBBs, strips the Fastman92 loader injection, and fixes the program header table location (prevents instant crashes on x86 emulators); supports `--libs-only` and `--clean`. |
| `gtasa_inspect.py` | Zero-third-party-dependency, dual-ABI (`arm64-v8a` / `armeabi-v7a`) offline disassembly and analysis tool for `libGTASA.so`, offering `find` (symbol lookup), `disasm` (disassembly with automatic PLT/GOT restoration), and `xrefs` (whole-library cross-reference scan). |

### `tools/gamedata/` — Game data package building, chunked publishing & local debugging
| Script | Purpose |
|---|---|
| `build_gamedata.py` | Based on official GTA:SA Android v2.10 (`--gtasa` / `dist/`) and PC GTA:SA + SA-MP 0.3.7 (`--pc-samp`), fully automatically converts and packages `dist/gamedata.zip`, ready for one-tap import in the launcher. |
| `publish_gamedata.py` | Packages a local game data directory and splits it into 16 MB chunks, generating `manifest.json` + `chunks/` (for the launcher's online chunked download), with optional `--upload` to push straight to Cloudflare R2. |
| `upload_r2.py` | Only uploads the `dist/cdn/` output already generated by `publish_gamedata.py` to Cloudflare R2 (supports resume-skip, retry on failure, and sampled HEAD verification). |
| `dev_rangeserver.py` | Local debug static server supporting HTTP `206 Partial Content` Range requests (with `--no-range` and `--slow` switches, for verifying client resume and poor-network fallback locally). |

### `tools/netcap/` — `/netcap` packet-capture offline analysis tools
| Source | Purpose |
|---|---|
| `ncapdump.cpp` | Parses binary packet-capture files recorded in-game via `/netcap` and lists a per-packet send/receive summary. |
| `ncapreplay.cpp` | Replays `/netcap` capture files offline to verify the client's `Net/Proto` unpacking behavior. |

> `tools/netcap/` is built together with `tests/native/CMakeLists.txt` into `build/native-tests/`, so it always stays in sync with the client's `Net/Proto/` source.
